## ☁️ How to Deploy Online (24/7 Link for Colleagues)

### 1. Create a Free Supabase Database (Takes 1 min)
1. Go to [supabase.com](https://supabase.com) and create a free project.
2. Open the **SQL Editor** in Supabase, paste this snippet and click **Run**:

```sql
create table if not exists qr_history (
  id bigint generated by default as identity primary key,
  title text not null,
  tab text not null,
  data_json text not null,
  customization_json text not null,
  is_favorite boolean default false,
  user_name text default 'Colleague',
  user_email text default '',
  created_at timestamp with time zone default timezone('utc'::text, now())
);

create table if not exists qr_templates (
  id bigint generated by default as identity primary key,
  name text not null,
  is_default boolean default false,
  config_json text not null,
  created_at timestamp with time zone default timezone('utc'::text, now())
);

create table if not exists qr_surveys (
  id bigint generated by default as identity primary key,
  survey_key text not null,
  name text not null,
  base_url text not null,
  fields_json text not null,
  created_at timestamp with time zone default timezone('utc'::text, now())
);

-- Enable public read/write for the app
alter table qr_history enable row level security;
alter table qr_templates enable row level security;
alter table qr_surveys enable row level security;

create policy "Public access" on qr_history for all using (true) with check (true);
create policy "Public access" on qr_templates for all using (true) with check (true);
create policy "Public access" on qr_surveys for all using (true) with check (true);
```

3. In Supabase **Project Settings > API**, copy:
   * **Project URL**
   * **anon public key**

---

### 2. Push to GitHub & Deploy to Vercel
1. In this folder:
```bash
git init
git add .
git commit -m "Initial commit of Orange QR Hub"
# create a repository on github.com (e.g. orange-qr-hub)
git remote add origin https://github.com/YOUR_USERNAME/orange-qr-hub.git
git push -u origin main
```
2. Go to [vercel.com](https://vercel.com), click **Add New > Project**, and select `orange-qr-hub`.
3. Under **Environment Variables**, add:
   * `NEXT_PUBLIC_SUPABASE_URL` = your Supabase Project URL
   * `NEXT_PUBLIC_SUPABASE_ANON_KEY` = your Supabase anon key
   * `SYNC_SECRET` = your chosen sync secret (e.g. `diaa-secret-2026`)
4. Click **Deploy**!
5. In ~30 seconds, Vercel gives you your link: `https://orange-qr-hub.vercel.app`. Send this one link to colleagues!

Whenever you want to pull whatever your colleagues created online into your local V17 `ld_center.db`:

```
GET https://your-app.vercel.app/api/qr/sync?token=diaa-secret-2026
```
